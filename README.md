# DraftSector

DraftSector enables advanced real-time data processing through distributed, auto-scaling clusters managed by a robust engine.

DraftSector is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftSector.git`
2. `cd DraftSector`
3. Install in editable mode: `pip install -e .`

## Configuration

DraftSector is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
